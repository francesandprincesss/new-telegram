Живая документация для gRPC Chat. Запросы из форм ниже идут в тот же доменный слой, что и gRPC, через локальный JSON/SSE facade.

Быстрый старт01—03
  1. 01
    Register или LoginJWT сохранится в sessionStorage
  2. 02
    Вызови защищённый RPCBearer добавится автоматически
  3. 03
    Открой Event ConsoleПроверь ONLINE / OFFLINE в реальном времени
Транспорт

Канонический API — gRPC на :50051. Этот интерфейс использует HTTP на :8080 только как удобный адаптер для браузера и ручного тестирования.

01

AUTH SERVICE

Регистрация и вход

POST/api/v1/auth/registerAuthService.Register

Создать пользователя

Username уникален без учёта регистра. Допустимы латинские буквы, цифры и _, длина 3–32. Пароль — от 8 до 72 символов.

Ответ появится здесь
{}
POST/api/v1/auth/loginAuthService.Login

Получить JWT

Возвращает access token. Неверный username и пароль дают одинаковый ответ, чтобы не раскрывать наличие аккаунта.

Ответ появится здесь
{}
02

USER SERVICE · JWT

Профили и поиск

GET/api/v1/users/meJWTUserService.GetMe

Текущий профиль

User ID берётся только из проверенного JWT. Эффективный статус учитывает активный Event stream.

Ответ появится здесь
{}
GET/api/v1/users/{user_id}JWTUserService.GetUser

Профиль по UUID

Возвращает публичные поля пользователя и его текущий effective presence.

Ответ появится здесь
{}
GET/api/v1/users/find?username=JWTUserService.FindUser

Точный поиск username

Поиск регистронезависимый: Alice и alice найдут одну запись.

Ответ появится здесь
{}
03

PRESENCE SERVICE · JWT

Статус пользователя

PUT/api/v1/presence/statusJWTPresenceService.SetStatus

Изменить ручной статус

Разрешены ONLINE, IDLE, DND. OFFLINE вычисляется сервером, когда нет активных подписок на события.

Ответ появится здесь
{}
04

EVENT SERVICE · JWT

Живые события

SubscribeEvents

GET /api/v1/events · Server-Sent Events facade

Отключено
События появятся после подключения. Открытый stream автоматически переводит пользователя из OFFLINE в выбранный статус.

ERROR MODEL

Коды ошибок

HTTP facade сохраняет смысл gRPC-кодов. Внутренние детали базы и секреты никогда не попадают в ответ.

HTTPgRPCКогда
400InvalidArgumentНекорректный JSON, UUID, username или статус
401UnauthenticatedНет JWT, токен просрочен или неверен
404NotFoundПользователь не найден
409AlreadyExistsUsername уже занят
500InternalНепредвиденная серверная ошибка
gRPC Chat / API v1Документ генерируется вместе с сервером
